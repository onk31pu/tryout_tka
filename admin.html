✏️ Token Manual (opsional)

Kosongkan untuk memakai token otomatis (dibangkitkan dari salt + tanggal, berubah tiap hari). Isi 6 karakter untuk memakai token manual yang sama di semua mata pelajaran.

ℹ️ Cara Kerja

  • Auto: token dihitung dari salt + tanggal hari ini. Otomatis berubah tiap hari pukul 00:00.
  • Manual: token tetap sampai Anda mengosongkan kembali field di atas.
  • Token berlaku untuk seluruh 12 mata pelajaran — peserta hanya perlu memasukkan sekali.
  • Tekan Ctrl+Shift+T di halaman ujian untuk melihat token (khusus pengawas).

🧂 Secret Salt Token

Salt digunakan untuk membangkitkan token harian (mode auto). Harus sama dengan yang ada di index.html dan halaman ujian. Mengubah salt akan mengubah token hari ini.

💾 Backup & Restore

Export konfigurasi ke file JSON untuk backup, lalu Import kembali jika diperlukan.

ℹ️ Informasi

  • Konfigurasi tersimpan di localStorage browser ini.
  • Agar berlaku di semua perangkat, distribusikan file konfigurasi JSON ke masing-masing perangkat siswa/pengawas.
  • Untuk multi-perangkat real-time, diperlukan backend (Firebase / API).
